One fortune cookie message for a software engineer — the bug you can never reproduce, reproducing itself at the worst possible moment, in front of your manager.

> The bug you cannot reproduce will reproduce itself in front of your manager.

## Run it

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt` (or `$ENTRY_OUTPUT`) and prints it.
